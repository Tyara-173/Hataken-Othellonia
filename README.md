# はたけんオセロニア

https://hataken-othellonia-beta.vercel.app/

## 概要

東〇王にあった漢字オセロみたいなやつです

## はじめかた

1. タイトルでユーザー名を決めます

2. 遊びたいジャンルを選んで対戦待ち

3. 同じジャンルを選んだ人がいたら対戦開始です

## ルール

1. 自分の石を置ける場所を選びます

2. 問題が出されるので，選択肢の中から解答を選びます

3. 正解だったら石が置けて，不正解だったら選んだ選択肢が消えて1に戻ります．3回まで間違えることができます（間違えた問題はそのターン中選ぶことができません）

4. 勝利した方の勝ちです
